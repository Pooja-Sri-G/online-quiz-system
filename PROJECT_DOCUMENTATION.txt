PROJECT OVERVIEW
================================================================================

The ASD Online Quiz System is a web-based application designed to allow users
to take online quizzes, track their scores, and generate certificates upon
completion. The system features user authentication, a quiz interface with
multiple-choice questions, result tracking, and PDF certificate generation.

Key Purpose:
- Provide a platform for online assessment and learning
- Track user performance and quiz results
- Generate professional certificates for successful quiz completion
- Manage question banks for quiz administrators
- Support user registration, login, and authentication

================================================================================
DATABASE MODELS
================================================================================

1. QUESTION MODEL
   - Fields:
     * question_text (CharField): The quiz question text (max 255 chars)
     * option1 (CharField): First multiple choice option (max 255 chars)
     * option2 (CharField): Second multiple choice option (max 255 chars)
     * option3 (CharField): Third multiple choice option (max 255 chars)
     * option4 (CharField): Fourth multiple choice option (max 255 chars)
     * correct_answer (CharField): The correct answer (max 255 chars)
   - Purpose: Stores all quiz questions and their answer options
   - Managed by: Django Admin interface

2. RESULT MODEL
   - Fields:
     * user (ForeignKey): Reference to User model (CASCADE delete)
     * score (IntegerField): Number of correct answers achieved
     * total (IntegerField): Total number of questions in the quiz
     * percentage (FloatField): Percentage score (e.g., 85.50)
     * date (DateTimeField): Timestamp of quiz submission (auto-filled)
   - Purpose: Tracks all quiz attempts and results for each user
   - Managed by: Django Admin interface

3. USER MODEL (Built-in Django)
   - Used for: User authentication, username, email, password management
   - Related to: Result model (one user can have many results)

HOW TO RUN THE PROJECT
================================================================================

1. Prerequisites:
   - Python 3.14+ installed
   - Virtual environment (venv) created

2. Setup Instructions:
   a) Navigate to project root directory
   b) Activate virtual environment:
      - Windows: venv\Scripts\Activate.ps1
      - Linux/Mac: source venv/bin/activate
   
   c) Install dependencies (if not already installed):
      - pip install django
      - pip install reportlab (for PDF generation)
   
   d) Navigate to quizsite directory:
      - cd quizsite
   
   e) Run migrations (if database needs setup):
      - python manage.py migrate
   
   f) Create superuser (admin account) - optional:
      - python manage.py createsuperuser
   
   g) Start development server:
      - python manage.py runserver
   
   h) Access the application:
      - Open browser to http://localhost:8000/

3. Admin Panel Access:
   - Go to http://localhost:8000/admin/
   - Login with superuser credentials
   - Manage questions and view results

================================================================================
KEY FUNCTIONALITIES BREAKDOWN
================================================================================

SIGNUP VIEW (signup_view):
- Accepts POST request with username, email, password
- Validates if username already exists
- Creates new User object if validation passes
- Redirects to login page after successful registration

LOGIN VIEW (login_view):
- Accepts POST request with username and password
- Authenticates user credentials
- Creates session for authenticated user
- Redirects to dashboard on success or shows error

LOGOUT VIEW (logout_view):
- Terminates user session
- Redirects to login page

DASHBOARD VIEW (dashboard_view):
- Displays user dashboard
- Accessible only to authenticated users

QUIZ VIEW (quiz_view):
- Retrieves all Question objects from database
- Renders quiz template with questions
- Displays all 4 options for each question

QUIZ SUBMISSION VIEW (submit_quiz_view):
- Processes POST request with user answers
- Iterates through all questions
- Compares user answers with correct_answer field
- Calculates total score and percentage
- Creates Result record in database
- Stores score in session for certificate generation
- Renders result page with feedback

CERTIFICATE VIEW (certificate_view):
- Retrieves user info from request
- Gets score and percentage from session
- Generates PDF using ReportLab
- Creates professional certificate with user details
- Returns PDF file for download

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Database not found
Solution: Run 'python manage.py migrate' from quizsite directory

Issue: Templates not loading
Solution: Ensure settings.py has correct TEMPLATES configuration

Issue: Static files not loading
Solution: Run 'python manage.py collectstatic'

Issue: Permission denied when running server
Solution: Check file permissions and virtual environment activation

Issue: Port 8000 already in use
Solution: Use 'python manage.py runserver 8080' (different port)
